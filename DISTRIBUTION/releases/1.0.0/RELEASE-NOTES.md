# CDX 1.0.0

CDX 1.0.0 is the first governed release of Conductellence (**Code of Conduct + Excellence**).

This release publishes the frozen CDX 1.0 constitutional and reference-runtime core after:

- adoption of `CDX-LAW-001 v1.0.0`;
- verification of the reference runtime and 69 fully automatable controls;
- SPETL v1.1 evidence compatibility;
- independent reference custody verification;
- native protected-main enforcement with required CDX checks;
- closure of the CDX 1.0 core release blocker set;
- explicit human-sovereign `RELEASE_1_0_0` decision;
- separate explicit human-sovereign authorization to publish CDX 1.0.0.

## Scope

Publication of CDX 1.0.0 means the **core release is versioned and published**.

It does **not** mean:

- estate-wide enforcement is complete;
- downstream repositories are automatically runtime-bound;
- FFOS, Pius, FFC, or other consumers are automatically admitted;
- WP08+ estate rollout is complete.

The governing maxim remains:

> Maturity is not enforcement. Release is not integration. Integration is not estate-wide enforcement.
